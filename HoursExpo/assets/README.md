# Assets

Placeholder files for Expo app icons and splash screens.

For now, Expo will use default placeholders. To customize:

1. Replace `icon.png` with a 1024x1024 PNG
2. Replace `splash.png` with a 1284x2778 PNG
3. Replace `adaptive-icon.png` with a 1024x1024 PNG (Android)
4. Replace `favicon.png` with a 48x48 PNG (Web)

The app will work fine with default Expo icons while testing!
